# Contributing to CyberNotes

Thank you for your interest in contributing to **CyberNotes**, created by **Kandula Paul Saketh Maurya** ([@MauryaKandula](https://github.com/MauryaKandula))!

## Development Setup
1. Fork and clone the repository:
   ```bash
   git clone https://github.com/MauryaKandula/cyber-notes.git
   cd cyber-notes
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the test suite before submitting a Pull Request:
   ```bash
   python test_cyber_notes.py -v
   ```
